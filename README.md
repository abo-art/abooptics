# 🕶️ AbooOptika — AI-платформа биометрического подбора смарт-очков Meta

Интеллектуальная B2B/B2C платформа компьютерного зрения и генеративного ИИ для сети премиальных оптических салонов **AbooOptika**. 

Сервис решает ключевую проблему оптического ритейла при продаже смарт-очков (Ray-Ban Meta, Oakley Meta): гаджеты весят больше классических оправ (46–50 г), имеют жесткие электронные заушники с батареями и требуют строгой миллиметровой посадки. Платформа оценивает посадку оправы в реальном времени, рассчитывает биометрию лица по 478 точкам, формирует персональный «Паспорт подбора» и консультирует клиента через мультимодальный ИИ **Gemini AI**.

---

## 🚀 Ключевые возможности

- **🕶️ Оценка посадки надетой оправы (Real-Time Evaluation):**
  - Клиент надевает физическую оправу с витрины салона и наводит камеру смартфона.
  - ИИ анализирует контур надетой оправы, положение зрачков в световом проеме и ширину рамки относительно скул.
  - **Вердикт стилиста-оптометриста:** точный расчет совместимости (0–100%), разбор давления заушников с батареями на височную кость и посадки мостика.
  - **Топ-5 идеальных альтернатив:** подбор анатомически выверенных моделей смарт-очков Meta с кнопкой быстрой выдачи с витрины.
- **💬 Интерактивный ИИ-стилист и консультант AbooOptika (Gemini AI):**
  - Непрерывный диалоговый режим с сохранением полного контекста переписки (Chat History).
  - Персонализация под биометрию клиента: после сканирования лица ИИ автоматически учитывает форму лица и результаты примерки.
  - Консультации по стилю и моде (streetwear-аутфиты, оверсайз худи, карго, кроссовки, деловой smart-casual).
  - Глубокое знание каталога: цены в казахстанских тенге (₸), линзы Transitions GEN S, диоптрии, характеристики камер и динамиков.
  - **Отказоустойчивость (Zero-Downtime):** каскадный fallback на локальный экспертный движок при недоступности внешних API.
- **🧠 Компьютерное зрение MediaPipe Face Mesh:**
  - Детекция 478 ключевых 3D-ориентиров лица в реальном времени.
  - Расчет геометрических метрик: соотношение длины лица к скулам ($H/W$), челюсти к скулам ($J/C$), угол подбородка и межзрачковое расстояние (PD в мм).
  - Классификация 6 типов лиц: *Овальное*, *Круглое*, *Квадратное*, *Сердцевидное*, *Продолговатое*, *Ромбовидное*.
- **🔒 Принцип абсолютной конфиденциальности (Privacy by Design):**
  - Лица клиентов **нигде не сохраняются**: обработка кадра происходит исключительно в оперативной памяти (RAM) за доли секунды.
  - Внешним сервисам (Gemini) изображение **не передается** (передаются только обезличенные текстовые коэффициенты).
  - Никакой базы данных с биометрическими слепками.
- **📄 B2B Паспорт стиля и талон консультанта:**
  - Печать талона примерки с точными калибрами (например, Wayfarer 50-22 или 53-22) для быстрой работы консультанта в зале.

## 🛠️ Стек технологий

- **Фронтенд:** Vanilla JavaScript (ES6+), HTML5, Tailwind CSS, MediaDevices API, Canvas API, Apple HIG Glassmorphism.
- **Бэкенд:** Python 3.11, FastAPI, Uvicorn, Pydantic v2, HTTPX.
- **Компьютерное зрение / ML:** MediaPipe Face Landmarker (Google Tasks Vision API), OpenCV Headless, Pillow, NumPy.
- **Генеративный ИИ:** Google Generative Language API (Gemini 3 Flash Preview, Gemini Flash) + Локальный эвристический fallback-движок.
- **Деплой:** Railway, Nixpacks, Docker.

## ⚙️ Быстрый старт локально

### 1. Установка зависимостей
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Создайте файл `.env`:
```env
GEMINI_API_KEY=ваш_ключ_gemini_api
PORT=8000
HOST=0.0.0.0
```
*(При отсутствии ключа сервис автоматически работает на встроенном локальном экспертном движке).*

### 3. Запуск сервера
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

- **Веб-приложение:** [http://localhost:8000](http://localhost:8000)
- **Интерактивная документация API (Swagger UI):** [http://localhost:8000/docs](http://localhost:8000/docs)
- **ReDoc:** [http://localhost:8000/redoc](http://localhost:8000/redoc)

## 📡 Спецификация API

| Метод | Эндпоинт | Тег Swagger | Описание |
|---|---|---|---|
| `GET` | `/` | — | Главная страница веб-приложения AbooOptika |

| `POST` | `/api/chat` | Gemini AI | Интерактивный диалог со стилистом и консультантом AbooOptika (Chat History) |

## 🏆 Демо-сценарий для жюри хакатона (За 1 минуту)

1. **Мгновенный тест без веб-камеры:**
   - Нажмите одну из демо-кнопок под видоискателем (*«Без очков»*, *«Квадратная оправа»*, *«Круглая оправа»*).
   - Посмотрите моментальный оптический вердикт, процент совместимости и Топ-5 рекомендованных моделей из каталога Meta.
2. **Паспорт примерки для консультанта:**
   - Нажмите *«Показать консультанту»* на любой рекомендованной оправе.
   - Откроется персональный талон с калибром оправы и оптометрическим обоснованием для выдачи с витрины салона.
3. **Умный диалог с ИИ-стилистом:**
   - Откройте плавающий чат в нижнем правом углу (обратите внимание на зеленый бейдж с учетом биометрии).
   - Задайте вопрос: *«расскажи мне про рейбан мета ген 3»* или *«посоветуй оверсайз аутфит под эти очки»*.
   - Задайте уточняющий вопрос: *«а сколько они стоят?»* — ИИ помнит контекст и ответит по модели из предыдущего вопроса.
