# 🕶️ abooptika — AI-сервис подбора очков по геометрии лица

Интеллектуальное веб-приложение для оптических салонов и интернет-магазинов. Использует компьютерное зрение (MediaPipe Face Mesh) для анализа пропорций лица через камеру смартфона, определяет форму лица и рассчитывает математический процент совместимости с формами оправ на основе оптической стилистики.

---

## 🚀 Возможности MVP

- **🕶️ Оценка надетой оправы в реальном времени (Real-Time Evaluation):**
  - Клиент надевает физическую оправу с витрины в салоне и наводит камеру.
  - ИИ анализирует пропорции лица, контур надетой оправы, центровку зрачков и ширину оправы относительно скул.
  - **Вердикт стилиста:** вывод оценки текущего выбора (например: *«Оправа "Квадрат": совместимость 82%. Хорошо подчеркивает скулы, но чуть широковата для вашего типа лица»*).
  - **Индикаторы посадки:** ширина оправы (Идеально/Широковата/Узковата), центровка зрачков в световом проеме линзы, соответствие линии бровей.
  - **Топ-3 альтернативы из каталога салона:** *«Попробуйте также примерить эти модели для идеального баланса»* (с фото изделия в каталоге, ценой, наличием в салоне и кнопкой *«Показать консультанту»*).
- **💼 Чистый профессиональный интерфейс (Без мультяшной графики):**
  - Никаких нарисованных поверх лица очков, накладных холстов и ползунков.
  - Только реальный снимок примерки и точная оптическая аналитика.
- **🧠 Высокоточный биометрический анализ (MediaPipe Face Mesh):**
  - Детекция 478 ключевых 3D-точек лица.
  - Расчет пропорций: отношение высоты лица к ширине скул ($H/W$), отношение челюсти к скулам ($J/C$), ширина зоны лба ($F/C$), угол подбородка и билатеральная симметрия.
  - Классификация 6 типов лиц: *Овальное*, *Круглое*, *Квадратное*, *Сердцевидное*, *Продолговатое*, *Ромбовидное*.
- **📐 Оптический алгоритм расчета совместимости (%):**
  - Применение правил геометрической компенсации и стилистики оптики (контраст форм, смягчение углов, визуальный лифтинг).
  - Индивидуальная калибровка процентов под биометрию клиента.
  - Подробные обоснования: *«Почему эта форма вам подходит»*.
- **👓 Интерактивная виртуальная примерка (Virtual Try-On):**
  - Автоматическая посадка выбранной оправы на лицо по координатам зрачков и углу наклона головы.
  - Возможность включения/выключения сетки 3D-точек лица (Face Mesh Landmarks).
  - Ручная тонкая подстройка масштаба и высоты посадки.
  - Сохранение фото примерки.
- **💼 B2B Режим для салонов оптики (Консультант Pro):**
  - Быстрое переключение интерфейса в режим терминала консультанта.
  - Формирование и печать «Паспорта стиля» (персональная карточка подбора для примерки в зале).
  - Онлайн-бронирование моделей в филиалах сети (Алматы, Астана, Шымкент).

## 🛠️ Стек технологий

- **Фронтенд:** HTML5, Tailwind CSS, Vanilla JavaScript, HTML5 Canvas 2D Engine, Web Audio API, MediaDevices API.
- **Бэкенд:** Python 3.11, FastAPI, Uvicorn, Pydantic v2.
- **Компьютерное зрение / ML:** MediaPipe Face Landmarker (Google Tasks Vision API), OpenCV, NumPy.

## ⚙️ Запуск проекта локально

### 1. Активация виртуального окружения
```bash
source venv/bin/activate
```

### 2. Запуск сервера FastAPI
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

Приложение будет доступно по адресу:
- **Веб-интерфейс:** [http://localhost:8000](http://localhost:8000)
- **Интерактивная документация Swagger API:** [http://localhost:8000/docs](http://localhost:8000/docs)
- **Альтернативная документация ReDoc:** [http://localhost:8000/redoc](http://localhost:8000/redoc)

## 📡 API Эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/` | Главная страница веб-приложения |
| `GET` | `/api/health` | Проверка статуса сервиса и модели ИИ |
| `POST` | `/api/analyze` | Анализ изображения (принимает multipart файл или base64 JSON) |
| `GET` | `/api/catalog` | Каталог оправ с фильтрацией по форме |
| `POST` | `/api/salon/booking` | Запись на примерку в выбранный салон |
